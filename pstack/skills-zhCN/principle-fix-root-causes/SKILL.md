# Fix Root Causes（修复根因）

修复故障本身，而不是它浮现的地方。根因是系统最早做了不该做的事、或没能处理本该处理的状态的地方。

- 先复现。不断问「为什么」，直到答案是代码里的一个错误决策。卡住时，加插桩，读实际状态。
- 追问触发症状的状态是否合法。如果合法，就在代码出错的地方处理它。如果它根本不该存在，在那里加检查只会掩盖 bug，要找出是什么产生了它。守卫、重试、吞掉的错误、被钳制的值、被丢弃的状态，都是掩盖 bug 的常见方式。
- 修复模式，而不是个例。找出所有存在同一故障的地方。
- 如果关键事实是深挖才找到的，提出一个廉价、常开的信号，让它第一眼就能显现。
