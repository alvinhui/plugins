# Explain the Number（解释数字）

- **跑之前先写下决策。** 写明什么结果会改变这个决策，以及噪声底。当多次运行的波动大于效应时，停下来。
- **问「为什么不能翻倍？」** 指出限制结果的资源或代码路径，依据是运行期间采集的 profile 或计数器。读代码猜出来的不算限制因素。
- **列出这个数字还可能测到了什么**（错误、被跳过或被缓存的工作、从未运行的代码、未调优的一侧、噪声、小到无关紧要的部分），并用证据逐一排除。
- **把运行次数、波动和限制因素与数字放在一起保存。**

对性能数字，运行 [benchmark-checklist](../benchmark-checklist/SKILL.md) 技能。对评测结果，追问每次运行是否都完成了任务、差距是否在多次试验和多个模型间成立、场景是否重要。
