# Model the Domain
（为领域建模）

把领域编码进数据结构，而不是散落在条件判断里。正确的结构让非法状态无法表示，并删掉分支。

用状态机替代散落的布尔值或阶段检查，用带类型的模型替代松散的参数，用映射、注册表或可辨识联合替代散布在多个文件里的分支，用 reducer 替代随手的修改；访问模式需要时，用索引、队列或规范化集合。

不要硬套。形状清晰、局部、不太会增长时，保留朴素的代码；对只增加间接层、却不消除分支或非法状态的抽象保持怀疑。

跳过本原则的迹象：一个功能让 if/else 链又多一个分支，或者出现第二个必须与第一个保持同步的布尔值。
