# Sequence work into verifiable units（把工作排成可验证的单元）

把工作排成小单元，每个单元都结束于你能检查的状态；当前单元没通过，就不进入下一个。

在批量清扫、迁移或成批相似编辑中，每个单元是一个闭环：已知良好的状态、一次变更、运行检查、继续。即使编辑由工具完成，也要运行每单元的检查。

按能证明工作的顺序交付：先失败的测试，再修复。先做减法，再重塑。先基线，后处理。每个提交独立合并。
