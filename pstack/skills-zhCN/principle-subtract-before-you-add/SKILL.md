# Subtract Before You Add
（先做减法，再做加法）

演进系统时，先移除复杂度，再构建。默认做减法。

把简化当成持续投资。离开时，让设计在你接手时相同或更小的接口面之下，稍微更简单、也更有能力。

- 把移除排在构建之前
- 先砍再打磨（先到最小集，再投入质量）
- 为观察到的用法设计，不为臆测的边缘情况设计
- 不做规格要求之外的臆测性校验器、解析器或守卫
- 简化提示词（移除冗余指令、过多模板）
- 引用没有新内容时，删掉它，而不是留一个空壳
