# Never Block on the Human（绝不阻塞等人）

人类是异步监督的。智能体必须保持不被阻塞。做出合理决策，继续推进，让人类事后纠偏。代码变更可逆、可评审，错误决策的代价通常小于阻塞。

- 先做，再展示。做完工作，展示结果。不要问「我该做 X 吗？」直接做 X，解释原因。
- 让系统自愈。发现问题时，记录下来，下一轮修复。
- 不可逆操作（force-push、删除生产数据、向外部发消息）仍需确认。
- 可逆操作（写代码、改笔记、拆任务）应当直接推进，不阻塞。
- 产品方向由人类决定。执行不应阻塞。
