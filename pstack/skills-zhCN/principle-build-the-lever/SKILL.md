# Build the Lever（打造杠杆）

工作不琐碎时，构建完成它的工具（codemod、脚本、生成器或可重跑的检查），而不是手工做。门槛是「是否琐碎」，不是「是否重复」。只有几处显而易见的编辑才可以不建工具。

- 先手工完成第一个单元，然后构建工具，并在该单元上重跑来证明它。让它重跑安全。
- 确定性的工具胜过并行分发。确实要并行分发时，把操作步骤、验证契约和护栏写成一个技能，供受委派的智能体阅读且不可编辑。
- 应用本原则会产出一个文件。diff 里没有脚本、codemod、生成器或委派技能，就说明你没有应用它。工作的寿命超出本次会话时，把它提交。
- 构建能完成或证明工作的最小脚本，绝不构建框架。
